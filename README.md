# RSSchool_2026Q2_Stage0.5__async-race

## Start local backend

```
git clone https://github.com/mikhama/async-race-api.git
cd async-race-api
npm i
npm start
```

## Start frontend

```
git clone https://github.com/pavelhalanin/async-race.git
cd async-race
npm i
npm run dev
```

## Deploy frontend to gh-pages

```
git clone https://github.com/pavelhalanin/async-race.git
cd async-race
npm i
npm run build
npx gh-pages -d dist
```
